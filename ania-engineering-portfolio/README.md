# Ania Pereira — Engineering Portfolio

A responsive static portfolio website built from the supplied Notion export.

## Preview locally
Open `index.html` in a browser. All project pages and images are stored locally in this folder.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `engineering-portfolio`).
2. Upload the contents of this folder to the repository root (not the containing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site; the URL will be shown in the Pages settings.

The site is plain HTML, CSS and JavaScript. No build tools or paid hosting are required.
